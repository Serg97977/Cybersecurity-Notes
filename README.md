# Cybersecurity Notes

Structured, in-depth notes documenting my journey toward professional
cybersecurity. Each note goes beyond definitions to explain **why** a technology
exists, **how it works internally**, the **attacks** against it, and the
**defenses** — the way a security engineer needs to understand it.

Most practical work is done in authorized lab environments: PortSwigger Web
Security Academy, locally hosted DVWA, and other legal practice platforms.

## Approach

Every topic follows the same lens:

> **What it is → Why it exists → How it works internally → Attacks → Defenses**

The aim isn't to collect commands, but to understand mechanisms well enough to
both attack and defend them.

## Ethics & scope

All techniques here are studied and practiced **only in authorized, isolated
environments**. Nothing in this repository is intended for use against systems
without explicit permission. Unauthorized access and testing are illegal.
Security knowledge is for building and defending systems responsibly.
